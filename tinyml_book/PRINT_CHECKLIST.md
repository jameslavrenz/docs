# Print-production and independent review checklist

- [ ] Independent embedded/ML engineer checks math, integer semantics, references, and code.
- [ ] Copyedit every chapter and verify heading numbering and glossary.
- [ ] Create proper front matter, acknowledgments, copyright page, and author biography.
- [ ] Verify print-provider trim, gutter, bleed, barcode space, cover spine width and paper stock.
- [ ] Export print-appropriate monochrome PDF with embedded fonts and no unsafe interactive links.
- [ ] Build a separate index for critical terms and API symbols.
- [ ] Add a real cover using title, subtitle, and author; inspect at full print size.
- [ ] Order and inspect a physical proof: equation legibility, page gutters, image sharpness.
- [ ] Validate optional book QR code and its permanent canonical URL.
- [ ] Replace demonstration-only classifier with an exported *trained* model and measured on-board full-graph inference before claiming a deployable application.
